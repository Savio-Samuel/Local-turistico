## 📖 Sobre o projeto

O **Local Turístico** é uma página desenvolvida para apresentar um destino turístico de forma organizada e visualmente agradável.

Este projeto foi criado com o objetivo de colocar em prática os primeiros conceitos de HTML e CSS, focando na estruturação do conteúdo e na estilização da interface.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

---

## 📚 Conceitos praticados

Durante o desenvolvimento deste projeto, pratiquei:

- Estrutura básica do HTML
- Fluxo de elementos (Flow do HTML)
- Estrutura semântica
- Inserção de imagens
- Box Model
- Margin
- Padding
- Variáveis CSS (`:root`)
- Organização e estilização com CSS
